# EZ_Book 

EZ book is a resaurant booking system that delivers an easy straight forward way to reserve a table at different restaurants.
With a simple user-friendly layout customers can view the menu, book a table and view my booking's.
With easy booking and editing to your existing booking's you can easily adjust or cancel.
Users are taken to a booking confirmation page after booking is complete.

### Feedback

Users have an option to submit feedback by choosing a button. All fields are required and verified by the code.

### Landing View

The website is built on a four pages to make it easy for users to navigate. Each page consists of the name of the restaurant and the options for users to choose according to their needs. All buttons have the same colour. For consistency purposes, home screen is the same across all devices.

### Menu View

All dishes are listed under different section, for example, Starters, Main Courses, Drinks and Desserts. Under each dish, there is a description of the dish and its ingredients for customers to know what to expect from their order.  

### Booking View

Users can check real- time availability to avoid disappointment due to lack of spot. They can cancel or make amendment to their bookings.

### 404 Page

In the scenario where the link may be broken, 404 page has a built in html link that brings you back to the homepage.

### Future Enhancements

Add on Maps for users who wish to visit the restaurant and unable toe find the location. Add on options of different sides and ingredients. For example, a vegan or gluten- free button for some dishes.

### Automated and Manual Testing

Automated testing uses scripts and tools to execute tests automatically. comparing actual results to expected outcomes.It is fast, reliable and great for repetitive tasks. like regression testing or checking basic functionality. Automated testing is used on every code change to catch bugs early, Large Test Suitefor when you have many tests and repetitive tasts, e.g login/ logout, booking and edit flows. Manual testing is when human testers explore the software trying to break it or fix issues. It is flexible, creative and catches UI/UX issuesor unexpected behaviour. It is used when there are new features, or to check for usability issues and old browsers etc.
